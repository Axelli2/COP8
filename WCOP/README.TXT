2. What is WCOP8 IDE?
---------------------
  The Windows COP8 Integrated Development Environment (WCOP8 IDE)
  was designed with the purpose of making the COP8 design flow more
  user friendly. Besides being an interface between the DOS assemblers/
  compilers and the Windows environment, the WCOP8 IDE is also a
  unique project handler which allows the user to combine several
  files in a project.
 
  The WCOP8 IDE main features are:
    - Supports both Windows 3.x and Windows 95
    - Windows Multiple Document Interface (MDI) environment. The 
      possibility to have multiple editors, each with a capacity
      of 16 Mb, open at the same time 
    - All known standard Windows editor facilities are available
      including bookmarks 
    - Assembling/compilation of a stand-alone file or a project by
      pressing a single button
    - Fast open of map and list files is available from the pop-up
      menu
    - Easy bug fixing facilities
    - Project view and source backup options
    - Easy-to-use project handling
    - Launch of external Windows applications
    - Templates

  Please download the WCOP8 IDE User's Manual for further information.

3. Requirements
---------------
  Minimum hardware requirements for the current version of the WCOP8
  IDE are:
    - IBM compataible PC (x386 or higher)
    - a minimum of 8 Mb RAM
    - a minimum of 2 Mb free diskspace

  The WCOP8 IDE also requires an MS-DOS 5.0 (or later) operational
  system and Windows 3.x or Windows 95.

6. How to uninstall WCOP8 IDE
-----------------------------
  If you for any reason would like to uninstall the WCOP8 IDE
  software follow these steps:

    - Delete the following files from the directory where the 
      WCOP8 IDE software is installed (default: c:\cop8\wcop8):
      Lncop.cfg, Dosinter.dll, Config.exe, Wcop8.exe,
      Shortcut.hlp, Asm.ico, C.ico, Inc.ico, Prj_asm.ico,
      Prj_c.ico, Untitled.ico, Startup.tst, Readme.txt,
      Whatsnew.txt
    - Delete the following files from the Example directory (default
      c:\cop8\wcop8\examples):
      Main.asm, Sub.asm, Main.inc, Test.prj
    - Delete the following files from the Template directory (default
      c:\cop8\wcop8\templates): 
      Module.tmp, Proc.tmp
    - If you did not add any other files to these directories they
      should now be empty and you can erase them
    - Delete the following files from the Windows directory:
      Wcop8.ini, Debugmod.pif, Epu.pif, Icedemo.pif, Icemast.pif,
      Wcop8.pif
    - Erase the WCOP8 IDE and WCOP8 IDE Configuration programs from
      the start menu or the Program Manager.
